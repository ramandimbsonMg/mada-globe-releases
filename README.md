# MadaGlobe for Android

Interactive 3D map of Madagascar: 24 regions, national parks, beaches, waterfalls
and cities. Works offline.

## Download

**[Download the latest APK](https://github.com/ramandimbsonMg/mada-globe-releases/releases/latest/download/MadaGlobe.apk)**

1. Open the link above on your Android phone (Android 7.0 or later).
2. Open the downloaded `MadaGlobe.apk` and allow installation from unknown sources if asked.
3. Launch MadaGlobe.

Web version: https://mada-globe.vercel.app

This repository only hosts the Android builds.
